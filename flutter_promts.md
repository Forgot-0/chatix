# Промпты для редизайна Chatix (Telegram-style)

Проект: Flutter + Riverpod 3 + go_router (`StatefulShellRoute`) + Clean Architecture.
Стек уже есть в `pubspec.yaml`: `cached_network_image`, `shimmer`, `flutter_form_builder`.
Ничего из этого менять не нужно — редизайн затрагивает только `presentation`-слой.

## Как этим пользоваться

1. Скармливай промпты **кодовому агенту с доступом к репозиторию** (Claude Code, Cursor, Windsurf и т.п.), **по одному**, в указанном порядке. Каждый следующий опирается на предыдущий (дизайн-токены → навигация → экраны).
2. После каждого промпта — `flutter analyze` и `flutter run`, глазами проверяешь результат, только потом следующий промпт. Не пытайся скормить всё за один раз: агент начнёт путаться между 6 экранами одновременно и получится мешанина стилей.
3. Если агент не видит контекст — вставляй в начало любого промпта фразу: *"Сначала прочитай lib/core/theme, lib/features/chat/presentation и lib/features/auth/presentation, чтобы понять текущую архитектуру, потом делай изменения"*.
4. Промпты 1 и 2 — фундамент, их не пропускай. Остальные (3–9) можно переставлять местами под свой приоритет. Промпт 10 всегда последний.
